03 · The Fine Print

About AI Features

Evexia's AI features (routines, diet plans, nutrition) use the Anthropic Claude API and require your own API key. Here's the honest breakdown:

  • ✓
    The API key is free. Sign up at console.anthropic.com in under 60 seconds.
  • ✓
    You pay pennies per month. ~1¢ per AI generation. A $5 deposit lasts most users 6+ months.
  • ✓
    Your key stays on your device. Stored locally. Never sent to us. Goes directly to Anthropic when you generate.
  • ✓
    Non-AI features work without a key. Tracker, splits, WODs, ranks, goals, community — all fully usable for free.
